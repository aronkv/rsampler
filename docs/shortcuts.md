# Keyboard shortcuts

| Key | Does |
| --- | ---- |
| <kbd>Space</kbd> | PLAY / STOP |
| <kbd>Shift</kbd>+<kbd>Space</kbd> | PLAY START |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> / <kbd>Ctrl</kbd>+<kbd>O</kbd> | REC / OVERDUB |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | UNDO SEQ |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | OPEN WINDOW |
| <kbd>+</kbd> / <kbd>-</kbd> | DATA wheel |
| <kbd>Delete</kbd> (hold) | ERASE |
| <kbd>T</kbd> | TAP TEMPO (stopped), NOTE REPEAT (held while playing) |
| <kbd>,</kbd> / <kbd>.</kbd> | STEP < / > |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | BAR << / >> (in the LOAD and SAVE lists: ten files up or down) |
| <kbd>Home</kbd> | GO TO start (in the LOAD and SAVE lists: the first file) |
| <kbd>End</kbd> | In the LOAD and SAVE lists: the last file |
| <kbd>F1</kbd>–<kbd>F6</kbd> | Soft keys |
| <kbd>F7</kbd> / <kbd>F8</kbd> | FULL LEVEL / 16 LEVELS |
| <kbd>F9</kbd> / <kbd>F10</kbd> | NEXT SEQ / TRACK MUTE |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Next / previous PAD BANK |
| <kbd>Ctrl</kbd>+<kbd>1</kbd>–<kbd>9</kbd> | SONG, MISC, LOAD, SAMPLE, TRIM, PROGRAM, SETUP, MIXER, OTHER |
| <kbd>Esc</kbd> | MAIN SCREEN |

The pad keys are on the [Pads](pads.md#playing-the-pads) page.
